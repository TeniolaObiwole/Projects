💬 F1 Miami Grand Prix Fan Sentiment Analysis

Coursework Project – May 2025 University of Westminster | Web & Social Media Analytics
📌 Project Overview
This project explores how Formula 1 fans reacted to new team merchandise drops during the 2025 Miami Grand Prix. Using Reddit as a data source, I analysed comments to understand fan sentiment and emotional tone across different teams’ announcements.

🧠 What I Did
Collected Reddit comments related to Miami GP merchandise
Pre-processed text data (tokenisation, lowercasing, stop word removal)
Performed emotion detection using the NRC Emotion Lexicon
Conducted word frequency analysis to find trending words by team
Presented findings in a written report and (privately) in a video summary

🔍 Key Questions
How did fans emotionally respond to each team’s merchandise drop?
Which emotions were most strongly associated with specific teams?
What topics or themes drove positive or negative reactions?

🧰 Tools Used
Python – data cleaning, analysis, visualisation
Libraries: NLTK, pandas, matplotlib
NRC Emotion Lexicon – for emotion detection
Jupyter Notebook – workflow and analysis
Reddit – data source (scraped from relevant subreddits)

🎯 Key Insights
Surprise and joy were commonly associated with Ferrari and McLaren merch drops
Anger and disappointment were tied to pricing and limited stock issues
“Drop,” “price,” and “limited” were among the most common trigger words
