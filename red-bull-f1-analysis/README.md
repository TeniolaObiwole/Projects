🏎️ Red Bull F1 Driver Performance Analysis
Coursework Project – December 2024 University of Westminster | Data Visualisation Module

📌 Project Overview
This project aimed to evaluate the performance of Red Bull Racing’s second driver, Sergio Pérez, during the 2023 and early 2024 Formula 1 seasons. With increasing media speculation and team pressure, the question was simple: Should Red Bull have replaced Pérez earlier in the 2024 season?
I used data visualisation techniques to draw performance comparisons between Pérez and other drivers, particularly his teammate Max Verstappen, to support a strategic recommendation.

🧠 What I Did
📊 Cleaned and structured race performance data using Excel
📉 Created line and bar charts to show trends in finishing positions, points per race, and qualifying gaps
📌 Compared performance against other second drivers on the grid
📍 Used Power BI for dynamic and interactive data storytelling

🎯 Key Insights
Noticeable drop in consistency and pace from Pérez post-mid-2023
Performance gap with Verstappen widened significantly across key races
Second drivers from other top teams showed tighter performance deltas

🧰 Tools Used
Excel (Data cleaning, structuring)
Power BI (Visualisation and Dashboarding)
